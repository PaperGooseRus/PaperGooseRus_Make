# PaperGooseRus Make: минимальное окно GTK4 на C++

Минимальный проект с GTK4 (C API) и GCC / G++ (C++17). При запуске открывается
пустое окно **PaperGooseRus Make**, размер по умолчанию 800 × 600.

## Структура

```text
PaperGooseRus_Make/
├── core/                 # место для логики проекта
│   └── .gitkeep
├── gui/
│   ├── gtk_app.hpp       # объявление класса gtk_app_t
│   └── gtk_app.cpp       # управление GTK-приложением и окном
├── pgr_app.cpp           # pgr_app_t и main()
├── main.bat              # сборка и запуск из Windows CMD
├── main.sh               # сборка и запуск из Bash
├── .gitignore
└── README.md
```

`pgr_app_t::run()` создаёт объект `gtk_app_t` и запускает цикл событий.
GTK посылает сигнал `activate`, после чего класс создаёт окно. При повторной
активации окно поднимается на передний план, вместо создания нового.
Закрытие последнего окна завершает цикл событий и программу.

## Требования

- Компилятор G++ с поддержкой C++17
- GTK4 (dev-пакет с заголовками и библиотеками)
- `pkg-config` / `pkgconf`

## Windows: MSYS2 UCRT64

Откройте **MSYS2 UCRT64** и установите зависимости:

```bash
pacman -S --needed mingw-w64-ucrt-x86_64-toolchain mingw-w64-ucrt-x86_64-gtk4
```

Проверьте:

```bash
pkg-config --modversion gtk4
```

Затем запустите `main.bat` из CMD (по умолчанию ожидает MSYS2 в `C:\msys64`)
или `./main.sh` из терминала MSYS2 UCRT64.

Переменные `MSYS2_ROOT`, `UCRT_BIN`, `PKG_CONFIG`, `OUTDIR`, `OUTEXE`,
`SRC`, `INCLUDES`, `CXXFLAGS` можно переопределить перед запуском BAT-файла.
`RUN_AFTER=0` позволяет только собрать проект.

## Linux

Установите GTK4-dev, g++, pkg-config средствами вашего дистрибутива.
В Ubuntu/Debian, например:

```bash
sudo apt install g++ pkg-config libgtk-4-dev
```

Далее:

```bash
./main.sh
```

## Этапы развития и проверка

1. **Старт**: собрать проект и убедиться, что появилось окно 800 × 600.
2. **Жизненный цикл**: закрыть окно и проверить завершение программы без ошибок.
3. **Повторная активация**: проверить, что не создаётся дублирующее окно.
4. **Развитие UI**: вынести окно в отдельный класс при добавлении элементов.

## Управление ресурсами

- `gtk_app_t` владеет `GtkApplication*` и вызывает `g_object_unref()`.
- `window` — невладеющий указатель; GTK управляет временем жизни окна.
- Обработчики сигналов `static`, объект передаётся через `gpointer`.
- Копирование и перемещение `gtk_app_t` запрещены.

См. документацию GTK4: https://docs.gtk.org/gtk4/getting_started.html
